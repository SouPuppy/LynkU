# Lucky 全面重构执行计划

状态：执行中；本文件保留目标设计与未完成工作。更新：2026-09-21。

## 交付目标

将现有社区原型迁移为按业务模块隔离、全栈严格 TypeScript、接口可验证、构建可复现、可持续由 Codex 维护的工程。完成必要的正确性修复，同时保留[产品契约](../../product/behavior-contract.md)中的功能与交互。

用户已授权本轮制定完整边界与治理方案。后续实施者可以在这些边界内自行决定普通实现细节，不需要逐个库、文件或函数向用户请示。正式恢复邮件、扩大产品范围、实际发布到哪个环境等不是本计划已经发生的事实。

2026-09-21 授权补充：当前原型允许破坏性重构，旧接口、目录和数据结构可直接替换，不承担旧客户端兼容义务；以下阶段中的兼容工作仅按实现过渡需要取舍，不能作为保留旧架构的硬性要求。用户指定账号与已有认证保留，数据操作按[数据迁移规则](../../architecture/contracts-and-data.md)执行。学校邮箱恢复已获授权，实际启用与云端验证进度以状态表为准。

“彻底”指消除重复业务源、隐式权限、无界读取和不可验证的状态；不以重写每一行、增加目录数量或换掉所有工具作为完成条件。

## 阶段依赖与总览

主路径 R0 → R1 → R2 → R3 → R4 → R5 → R6 → R7；R8 的可执行准备贯穿全程，真实环境验证在具备条件时穿插进行。前一阶段不是必须一次全仓库重写；可以拆成能独立验证的切片。

| 阶段 | 范围 | 本地完成的关键证据 |
|---|---|---|
| R0 | 功能与工程基线 | 实际接口/权限差异清单、回归基线、工作区保护记录 |
| R1 | workspace、构建、类型与边界检查 | 微信与独立云函数试验产物、违规依赖被拒绝 |
| R2 | 契约、身份上下文与请求边界 | 每个 action 明确策略、旧接口适配、私有读写授权测试 |
| R3 | 消息首个完整纵向模块 | 同步无遗漏、会话隔离、完整目录及已读模型、回填 |
| R4 | 内容、评论与通知一致性 | 幂等与事务、outbox 消费、计数核对、移除读时修复的条件 |
| R5 | 身份、草稿与其余业务迁移 | 资料事件、学校邮箱认证恢复、草稿并发隔离、服务端业务 TS 收口 |
| R6 | 前端状态与目录收口 | 页面薄化、会话代际/缓存/轮询统一、分包与旧路径迁移 |
| R7 | 工程治理闭环 | CI、干净构建、现行文档、遗留退出、可运行的验收/恢复脚本 |

R0–R7 完成可以报告“本地重构完成”；只有 R8 也完成且无上线阻塞才能报告“技术上线验收通过”。不能因缺平台访问权限就停止独立的本地实现，也不能用本地假对象测试代替云端证据。

## R0：冻结可验证基线

**输入：** 当前工作区而不是仅 Git HEAD；已有游客改动属于需要保留的基线。

**工作：**

- 记录分支/HEAD、未提交修改和未跟踪文件、可用检查、实际本地工具版本；采用不会丢失这些修改的工作方式。若使用隔离目录，需包含本次工作区基线，不能从旧 HEAD 丢掉游客功能。
- 盘点 14 个主包页面、聊天分包、6 个生产函数以及所有 action；给每个 action 关联权限、输入、响应、集合与相应验收 ID。
- 当前入口清单：users 的 ensure/updateProfile/getProfile/sendEmailCode/verifyEmailCode/drainProfileOutbox；posts 的 list/get/create/search/delete/update/flag；comments 的 list/syncChanges/create/delete/drainOutbox；messages 的 send/listConversations/getConversation/syncConversation/markRead/listNotifications/getUnreadNotificationCount/markNotificationsRead；categories 的 list/seed/create/update；drafts 的 save/list/delete。两个 drain 入口仅供管理员执行故障恢复，不能接入常规客户端流程。执行时重新核对，不能把快照当永久事实。
- 建立合成 fixture：无账户/未认证/已认证/管理员、普通/匿名内容、同一对用户的多种会话、大量同时间消息、超历史扫描窗口会话、离线草稿、审核/删除状态。
- 区分保留行为与缺陷；对关键权限、匿名隔离、游标、幂等、计数和会话竞态建立失败复现或行为刻画。预期失败用例进入可追踪回归包，不能把主检查永久置红或将失败测试全部 skip。
- 记录包体/请求数量/轮询与可取得的运行基线，纠正旧文档与代码不一致的事实条目。

**退出：** 已有检查通过；行为差异有证据和阶段归属；A01/A12 基线明确。R0 不要求一次编写全部未来测试，后续每个缺陷在修复前补足对应测试。

## R1：建立工程底座并证明可打包

**工作：**

- npm workspace、基础/平台 TS 配置、锁定依赖及本地工具说明；新包可先进入 packages，原页面/函数目录暂留。
- 选择格式化、静态检查、架构检查、schema 和构建方式。用一个真实 DTO/用例及一个云函数做最小试验，不只编译 hello world。客户端需实际加载共享校验代码，函数产物需能独立解析依赖。
- 固化 package exports、模块依赖规则及违规样例；新 TS 模块启用严格增强选项。对未迁移 JS 明确列出范围，而不是全仓库模糊豁免。
- 建立统一的函数/环境 manifest 方向，避免 functions.sh、cloudbaserc 和构建脚本各自维护不同清单。
- 所有新命令先在根 scripts 中真实可运行再写入开发文档；构建不修改旧源码、生成物落独立目录。

**退出：** G1 基础门槛通过；R0 回归不退化；架构/类型违规确实会失败；产物试验与工具选择 ADR 可追溯。没有微信工具访问时，可完成本地产物解析，但实际微信加载列入 R8，不虚报。

## R2：统一协议与授权入口

**工作：**

- contracts 按动作定义 schema、错误、分页和公开/本人/匿名 DTO；新旧协议之间只做转换。
- 所有云函数 action 注册访问策略；服务端通过可信 OPENID 查询 Principal，业务用例只获得必要能力。补齐私信/草稿/通知读写认证，先授权再幂等返回。
- 建立 identity 窄接口、公开 userId 映射方案及迁移；公开与本人资料分离。邮箱暂停保持，不恢复真实邮件。
- 统一 transport 错误、请求标识、关键响应解码和客户端会话代际接口。禁止客户端构造信任身份。
- 准备可复用的 Clock/IdGenerator/事务能力等真正需要的端口，不提前建立空泛基础框架。

**退出：** A02/A03/A12/A14；每个动作策略可审查。内部旧业务仍可经适配层运行，登记迁移范围；完整 identity 资料/邮件实现收口在 R5。

## R3：消息作为第一个完整迁移样例

**工作：**

- 从用户界面调用、schema、应用用例、领域规则到 CloudBase 适配器贯通，建立一个其他模块可照做的样例。
- 会话/成员作为权限与目录基础，分离普通及匿名会话；既有匿名会话依成员授权，不能只依来源帖是否仍公开。
- 实现历史分页与可靠增量同步，覆盖同时间变更、分页期间状态更新、初始快照交接、过期游标与失败恢复。优先采用每会话变更序列，若平台限制需调整则按 ADR 验证替代方案。
- 发送幂等、已读位置、未读和摘要并发维护；角标不再扫描截断的消息/会话样本估算总量。
- 准备旧消息到会话/成员/同步模型的可重入回填、核对和兼容读。匿名身份映射仅留服务端。
- 客户端先应用数据再推进游标；停止/登出/切换会话后旧响应失效。

**退出：** A04–A07、A11/A13/A14 的消息部分；超旧扫描范围与同时间超页回归通过；新旧接口走同一业务实现。不得仅修时间游标就声称完成消息迁移。

## R4：内容、评论与通知

**工作：**

- 迁移帖子、分类、评论与回复规则，公开读/本人读明确分离，保留审核/删除与两级回复语义。
- 创建幂等、版本冲突与事务计数，评论写入必须在提交范围内复核帖子/父评论状态。
- 持久化 outbox 与受控消费者；通知生成/资料投影支持去重、重试、租约与失败可观测。先有补偿能力再考虑移除旧读时回填。
- 评论分页与增量刷新协议先行，避免页面长期全量加载；搜索先做有界查询和稳定分页，不引入无证据需要的新搜索平台。
- 回填并核对通知与公开计数；对已有投影脏数据提供受控修复而不是请求中临时补表。

**退出：** A03/A07–A09/A13/A14 内容部分；后台失败不导致重复发帖/评论。迁移投影追平和消费者真实运行尚未云端验证时，切换门槛保留在 R8。

## R5：身份、草稿与业务收口

**工作：**

- users 的资料/认证实现迁为严格 TS；验证码、邮件、频率/尝试次数使用独立能力和测试，默认暂停状态不变。
- 昵称头像变更经版本化事件更新非匿名快照，消费由内容/通知拥有；移除身份用例直接跨集合写入。
- 云草稿按所有者鉴权，初次保存幂等、更新有版本保护、数量上限在并发下有效。既有“最多 50 个”的产品上限在未明确改变前保留。
- 服务端所有旧 JS 业务与公共 utils 副本退场；legacy 目录只可保留有退出条件的协议转换，不能留独立业务。
- 限流故障策略、错误规范、管理审计、公开标识迁移收口；私人缓存与身份变化接口对接前端。

**退出：** A02/A03/A07/A09/A10/A12；全服务端业务进入类型/边界检查；邮箱暂停及历史认证回归通过。

## R6：前端业务状态与最终目录

**工作：**

- 编辑器提取 editor feature；保存/发布/清理和恢复按内容版本协调。全局匿名偏好与具体草稿/帖子的匿名值边界明确。
- 会话管理统一初始化、显式登录、游客选择、登出与代际失效；资料更新等所有私人异步路径都遵守失效协议。
- 轮询、分页、角标、列表/详情刷新不重复管理同一状态；统一取消/退避/恢复规则，私人存储按账户隔离。
- 页面和通用组件保持薄层；email-verify 已迁为 TS 并复用统一认证、会话和 users 服务。保留已有视觉、路由参数和分享链接，必要兼容映射有测试。
- 在真实构建方案已验证后移动到 apps，更新 project.config、分包路径、脚本、测试及资源引用；检查未被引用的资源不误删。

**退出：** A01/A10/A11/A14/A15；全部页面功能矩阵完成本地验证，G4 设备项有明确步骤；没有双份 session/store/服务逻辑并行维护。

## R7：治理闭环和遗留退出

**工作：**

- 统一根 check 包含静态、类型、架构、行为和必要构建检查；耗时云/设备测试独立命令且报告环境前提。CI 使用相同命令和锁定依赖。
- 用等价行为检查替换脆弱源码形状断言；清理旧共享工具复制、重复配置、废弃入口/文档及未引用业务文件。
- 更新 README/DEVELOPMENT/AGENTS 为现实路径与命令；整理历史文档导航，保留有价值决策，文档链接检查通过。
- 产物、配置、权限/索引 manifest、数据迁移、后台消费者、日志/告警、恢复流程和测试 fixture 完整；运行手册从草案变为真实命令。
- 从干净安装重建并执行完整本地验收，记录支持矩阵、包体、代表数据规模及性能/调用成本预算。
- 查找仍存在的 any/双重断言/宽泛忽略/空 catch/直连 SDK/旧业务源，对实际风险逐项处理；不能用零匹配当业务正确性的替代。

**退出：** G1/G2 完整通过；A01–A15 本地证据可定位；每个暂留兼容项有必要性与退出条件；所有原功能在新结构有映射；R8 可执行，外部未验证项单列。

## R8：平台验收与发布准备

在明确的隔离环境及可用工具上执行 G3/G4、迁移/恢复演练和性能测量；核对索引、权限、云运行时和后台调度实际工作。

邮箱服务恢复、真实审核与数据保留政策没有结论时记为上线阻塞，不通过改文案/跳过校验来消除。任务若不包含正式发布则产出可发布产物与发布清单，不自行宣称已经上线。

缺少环境/设备时记录精确前提、命令、测试数据准备与预期结果；本地工作完成后明确报告边界，不无限等待也不伪造通过。

## 自主决策与变更治理

可自行决定：库版本和构建工具、类/函数细节、索引布局、文件拆分、适配器实现、普通 bug 修复和有证据的性能优化。影响架构/契约时补 ADR，更新状态并继续执行。

本轮已决定的目标修正包括：补齐私有端点认证、先授权后幂等、普通/匿名会话隔离、稳定同步、旧匿名会话按成员访问、公开标识分离、创建幂等、按版本写入、通知可靠补偿、限流故障策略。它们不得被“保持原样”挡住。

如必须变更已定产品范围、公开匿名真实身份、更换托管平台或清除真实数据，需重新界定任务范围；普通技术选择不属于此类。既有明确授权持续有效，不为文档中的流程重复索取授权。

不设拍脑袋工期或文件数量指标。每个工作单元应能说明行为、边界、测试和迁移；遇到一个模块困难可先完成其他不依赖部分，但必须回到未完成验收，不能换名宣布完成。

## 防止重构失控

| 风险信号 | 执行规则 |
|---|---|
| 持续写设计、迟迟不实现 | R0/R1 足够支撑首个切片后进入 R2/R3；不再复制本计划生成同义文档 |
| 新旧代码双轨无限延续 | 每个兼容层指定调用者与退出条件；一个动作只能有一个业务实现 |
| 大量空目录/抽象 | 用真实消息切片验证，未消费的框架层不计成果 |
| 为通过检查删测试/放宽类型 | 对应验收必须仍有证据；替换前比较保护范围 |
| 本地测试假阳性 | G3/G4 单独列出，真实环境限制不能被 mock 掩盖 |
| 历史文档重新引入旧需求 | 以产品契约和当前用户要求为准，旧方案只作背景 |
| 上下文压缩后重复劳动 | 恢复先核对 status 与代码，再续做下一个切片 |

完成状态只写入 [status.md](status.md)，本计划定义工作而不复制进度百分比。
