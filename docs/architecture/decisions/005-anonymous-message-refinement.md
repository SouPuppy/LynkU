# ADR 005：匿名消息精修与恢复边界

日期：2026-09-23。状态：已在本地实现，待人工审核及 G3/G4 验证。

用户要求保护匿名身份、修复消息提醒，同时保留现有 UI 范式。采用原页面内的身份说明、待确认状态及匿名局部深色提示，不新增导航体系。

会话身份由服务端按本人和对端分别投影，已建立通道不随全局匿名偏好变化。匿名互动通知编号不含隐藏作者标识；旧编号必须经过维护窗口迁移后才可公开读取。编辑匿名内容为昵称身份需确认。

发送操作持久保存原消息编号和正文，自动恢复仅查询结果并退避；只有用户明确重试才发送同一操作。已读仅确认可见条目，摘要作为角标唯一所有者，迟到结果不能覆盖更新状态。

屏蔽仍在私有账户对层执行，但对用户仅公开其本人操作记录。独立匿名通道的屏蔽操作分别撤销，不合并匿名别名，也不公开账户对标识。旧数据缺少来源时保留“历史屏蔽记录”，不猜测身份。代价是同一对端存在多次操作时需逐项撤销；这是避免向用户暴露通道关联的明确选择。
