## Scope

Change all 4 `onAuthorTap`/`onActorTap` handlers to navigate to profile page instead of directly to chat.

| Location | Before | After |
|----------|--------|-------|
| `post-item.ts` | `wx.navigateTo → chat` | `wx.navigateTo → /pages/user/user?openid=<id>` |
| `comment-item.ts` | `wx.navigateTo → chat` | same |
| `post.ts` | `wx.navigateTo → chat` | same |
| `notification-card.ts` | `wx.navigateTo → chat` | same |

The profile page has the "发私信" button for chat initiation.

### Handler simplification
Since all handlers now navigate to the same URL pattern, the logic simplifies:
```
onAuthorTap(e):
  author = e.currentTarget.dataset.author
  if !author || anonymous → return
  if author._openid === getOpenid() → still navigate (view own profile)
  wx.navigateTo({ url: `/pages/user/user?openid=${author._openid}` })
```

Self-tap now navigates to own profile (was: no-op). Anonymous still no-op.
