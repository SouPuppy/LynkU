## Scope

Convert the Messages page from a single conversation list into a two-tab view:

- **Tab "私信"**: Existing conversation list (unchanged behavior)
- **Tab "系统消息"**: Inline notification feed using `notification-card` component, with cursor-based pagination, pull-to-refresh, and load-more

Changes:
1. Remove the notification stub row (no longer needed — replaced by tab)
2. Add tab bar at top: two segments "私信" / "系统消息 (N)" with active indicator
3. Tab "系统消息" renders notification feed inline (bring in from notifications page)
4. Notification tap → deeplink to post detail (existing behavior from notification-card)
5. Mark notifications read when tab is viewed
