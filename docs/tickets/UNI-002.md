## Scope

Add tap handlers on avatars and usernames to navigate to the chat page.

### Components to modify

| Location | Elements | Handler |
|----------|----------|---------|
| `post-item` | Author avatar + name | `onAuthorTap` → navigate to chat |
| `comment-item` | Comment author avatar + name (top-level + replies) | `onAuthorTap` → navigate to chat |
| `pages/post/post.wxml` | Post author avatar + name | `onAuthorTap` → navigate to chat |
| `notification-card` | Actor avatar + name | `onActorTap` → navigate to chat |

### Handler logic

```
onAuthorTap(e):
  author = e.currentTarget.dataset.author  // { _openid, nickname, avatar_url }
  if author.anonymous → return
  if author._openid === getOpenid() → return (no self-chat)
  wx.navigateTo({
    url: `/subpkg-chat/pages/chat/chat?peer=${author._openid}&name=${author.nickname}&avatar=${author.avatar_url}`
  })
```

### Data binding

Each avatar/name wrapper needs `data-author="{{...}}"` with the full author object. For anonymous users, add `data-anonymous="{{true}}"` to skip navigation.
