## Scope

Show total unread count on the Messages tab bar badge:

```
tabBar badge = unread conversations + unread notifications
```

### Implementation

1. After loading conversations → sum `item.unreadCount` across all conversations
2. After loading notifications → call `getUnreadCount()` from `services/notifications`
3. Set `wx.setTabBarBadge({ index: 1, text: String(totalUnread) })` on the Messages tab
4. Update in `onShow` (every time user views the tab)
5. Clear badge when total reaches 0: `wx.removeTabBarBadge({ index: 1 })`

### Edge cases

- Badge text max 99+ (WeChat limit)
- Mix of conversations and notifications unread
- Tab bar index: Messages is tab index 1 (0=首页, 1=私信, 2=我的)
