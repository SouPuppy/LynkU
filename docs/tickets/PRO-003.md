## Scope

Add `getPostCount(openid)` to `services/users.ts` — returns the count of published posts for a user. Used by the profile page to display "N 篇帖子".

```typescript
export async function getPostCount(openid: string): Promise<number> {
  const res = await coll.posts
    .where({ _openid: openid, status: 'published' })
    .count()
  return res.total
}
```
