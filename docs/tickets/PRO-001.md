## Scope

Create `pages/user/user` — a public profile page showing:
- Large avatar + nickname
- Unique handle: `@` + first 10 chars of `_openid`
- Join date (from `created_at`)
- Post count (from `services/users.getPostCount`)
- "发私信" button (hidden if viewing own profile)
- Recent published posts list (20 posts via `listPosts({ authorOpenid })`)

### URL params
`/pages/user/user?openid=<openid>`

### Edge cases
- User doc not found → show fallback (default avatar, "微信用户", handle still from openid)
- Self-view → hide "发私信" button
- Anonymous user → still shows handle (openid is public info)
