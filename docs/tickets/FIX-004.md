## Scope

Extract the duplicated LoadState management pattern into a WeChat `Behavior`.

### Behavior API

```typescript
// behaviors/loadstate.ts
const LoadStateBehavior = Behavior({
  data: {
    state: 'idle' as LoadState,
    errorMsg: '',
  },
  methods: {
    setLoading() { this.setData({ state: 'loading', errorMsg: '' }) },
    setLoaded()  { this.setData({ state: 'loaded' }) },
    setEmpty()   { this.setData({ state: 'empty' }) },
    setError(msg?: string) {
      this.setData({ state: 'error', errorMsg: msg || '加载失败' })
    },
  },
})
```

### Migration

Replace manual `setData({ state: ... })` calls with `this.setLoading()`, `this.setLoaded()`, etc. across pages.
